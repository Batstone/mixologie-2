Welcome to **Mixologie**, a cocktail app that allows users to discover, explore, and get recipes for a variety of cocktails. Built with Next.js, this app fetches cocktail data from the Cocktail API and presents it in a sleek, user-friendly interface.

## Features

- **Browse Cocktails**: Explore a wide variety of cocktail recipes.
- **Search Functionality**: Search for cocktails by name or ingredients.
- **Responsive Design**: The app is fully responsive and works on mobile and desktop devices.
- **Favorite Cocktails**: Save your favorite cocktails for easy access later.

## Technologies Used

- **Next.js 14**: A React framework that enables server-side rendering, static site generation, and more.
- **Cocktail API**: Provides data on a wide variety of cocktails.
- **React**: Used for building the user interface with hooks for managing state and effects.
- **CSS/Styled Components**: For styling the app's UI components.
